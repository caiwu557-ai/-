## 题干、判分与出题模式

- **364 题保存在题库浏览**，没有删除图像或更改稳定 ID。
- **43 题**因原图片多标签/箭头目标未唯一确认，改为**仅核查，不参与自动组卷**。原版仅从模拟考试排除，这次拓展到综合、新图和错题强化，避免形成错误记忆。
- **6 题**标记补充，其中 Q0198 同属上述 43 题，因此当前自动练习及模拟考试共 **316 题**。
- 余下问题不被宣称为逐图专家核准，只能说没有发现足以排除的明确证据；继续支持用户标记问题。
- 题干由原本无差别的「图中所示的结构是什么」改成区分器官整体、标注细胞、目标组织和结构四种任务；另对 Q0318 等使用场景给出不包含答案的指令。
- 题干不含任何题目中英文标准答案；公布答案仍发生在作答后（模拟考试为完卷后）。
- 自动判分仅接受中英文目标名和明确审核过的同义名，功能描述、旁边编号不算。
- `qa/scope_decisions.csv` 与 `qa/question_audit.csv` 每题保存状态、理由、提示文本与出题权限。

## Chromium 真浏览器验证

本环境在加载 `file://` 和 `127.0.0.1` 时受到管理员网络策略限制。为实现用户要求的实际浏览器测试，不去绕过该限制：测试脚本将**同一份 HTML、CSS、JS 和选中的原版 WebP 数据内联到 `about:blank` 文档**，由系统 `/usr/bin/chromium` 在真实 DOM/布局/鼠标与模拟触控下执行。

- 执行：`python qa/browser_inline_v2.py`
- Chromium 四档宽度：1440、768、390、320 px；`prefers-reduced-motion:reduce` 另测。
- 测试点：首屏 364/316 数字、手动点训练模式+开始、真实 WebP 解码、Q0318 源答案排除与修订答案、无答案泄露、严格同义判分、放大图+Escape、题库中补充 6/待核验 43 精确数量、禁用其单题自动训练、移动视口溢出、学习记录及 JS 异常。
- 首轮发现真实 UI 故障：前版本的 `module-footer` 放在页面状态容器外，导致练习和题库页顶部重复出现授权说明；按钮 SVG 使用浏览器默认大尺寸，导致提交按钮出现超大箭头。两处已修复并复测。
- **最终：37 / 37 PASS，0 FAIL**。截图在 `qa/browser-evidence-v2/`，视图参考 `visual-contact-v2-final.jpg`。
- 边界：虽然这是真实 Chromium，但它不验证原生 HTTP 文件相对路径、跨模块导航 URL、GitHub Pages 构建状态，也不等同于所有 364 张图片逐张形态学专家审核。上线前仍需在实际部署域名复测。
