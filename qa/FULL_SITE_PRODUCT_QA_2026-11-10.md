# LUMEN · 全站产品品质审查

范围：概览、今日复习、术语词库、学习记录、偏好设置、专注训练，以及组织切片图谱总览、组织/器官目录、阅读小节、G01–G45 对照和图片弹窗。

## 产品约束

- 术语主动回忆为核心，显微切片图谱负责提供结构定位和易混对照证据。
- 保留 1269 术语、练习节奏、复习规则、完成一轮后的继续学习入口及本地学习记录键 lumen_histology_recall_v1。
- 图谱保持独立站内模块，视觉规范、操作反馈和导航与学习工作台保持一致。
- 所有改善在 Draft PR 内审查，不合并 main 或发布 Pages。

## 六维度审查矩阵

| 严重度 | 维度 | 问题 | 当前行动 |
|---|---|---|---|
| P1 | 信息架构/效率 | 小节内使用搜索只过滤侧栏，不展示结果 | 全页面搜索组织/器官和对照组；标题优先排序 |
| P1 | 操作效率/反馈 | 搜索后手机抽屉遮挡结果 | Enter 确认、关闭抽屉、焦点进入搜索结果 |
| P1 | 用户流程 | 图谱路由 replaceState 导致浏览器后退失效 | pushState + popstate/hashchange |
| P1 | 组件一致性/无障碍 | 图片 onclick 非键盘入口；关闭弹窗焦点丢失 | 原生按钮、键盘放大、焦点陷阱与恢复 |
| P1 | 反馈机制 | 图片断链显示空白，懒加载容易误判 | 仅在真实 error 时退化到来源链接 |
| P2 | 信息架构 | 词库单词与同器官图谱缺少结构化往返 | 建立带器官约束的词条搜索入口，禁止同名误配 |
| P2 | 操作效率 | 手机搜索仍需先打开侧栏 | 在顶栏设置显式搜索入口，减少一次动作 |
| P2 | 视觉层级 | 图谱总览统计与众多分类入口同级 | 把“开始识图”和“易混训练”变为明确主/次操作 |
| P2 | 组件一致性 | 图谱与主站 Logo、卡片、导航细节存在差异 | 统一 design tokens、圆角、图标、焦点与状态 |
| P2 | 用户信任 | 仍有少量仅为器官示例的图片 | 核查来源有效性，并区分标注图/定位图/技术示例 |
| P2 | 反馈机制 | 跨标签主题切换不能立刻同步 | 监听 storage、同步主题但不重置学习记录 |
| P2 | 情绪体验/性能 | 多种光学特效和图表长期占据感知资源 | 量测低端设备负载并验证 reduced-motion |
| P2 | 效果评估 | 缺少真实医学学习任务的成功率基线 | 进行用户测试：首答、复习、识图与易混对照 |

## 验收与边界

- 图谱本地 Chromium 测试：390×844、820×1180、1366×768，覆盖目录→搜索→条目、历史后退、45组展示、图片键盘操作、关闭恢复、错误图反馈与横向溢出。以上是本地数据内联测试，不等于生产 Pages 部署验证。
- 回归：node --check atlas/atlas.js、node qa/validate-atlas.mjs、node qa/validate-atlas-interactions.mjs。
- 主站已有的 validate-terminology、validate-learning-flow、validate-round-prompt 须在合并前重新执行。主站所有训练业务逻辑没有在本轮中被改写。
- Awwwards、Webby、FWA 是审美和产品品质目标，而非通过认证。需完成实机测试、真实用户任务测试、性能量测、无障碍审查和细节设计后再作总体判断。
