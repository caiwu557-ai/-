# LUMEN 视觉与交互验收基线 · Clarity v1

适用范围：学习工作台、组织切片图谱、看图填空。该文件作为后续界面迭代的质量门禁，不能替代医学内容校审。

## 视觉原则

- 保留 LUMEN 的深蓝导航与紫色操作强调；正文使用中性背景、平面卡片和轻边框，避免泛滥渐变、发光和装饰性阴影。
- 学习操作优先于装饰：选训练模式、观察图片、输入答案、看反馈，是最先被注意到的视觉层级。
- 主站工作台的视觉焦点是正在进行的学习任务；图谱的焦点是显微切片与临床视觉判别线索。
- 标题、正文、图注按层级组织，不为密集数据牺牲可读性。新增辅助文字不得小于 11px。
- 颜色不得成为唯一状态线索；禁用、错误、继续、完成都必须有可辨识文字或形态。

## 关键交互验收

- 1440 / 768 / 390 / 320px 无水平页面溢出，切换亮暗主题后文字与操作保持可辨。
- `atlas/#sec-7-2` 厚皮与薄皮对照表应占据接近完整文章宽度；两张参考图不能因 `auto-fill` 出现又窄又小的卡片。图片使用 `object-fit: contain`，不得偷偷裁切病理结构。
- 手机看图填空：观察图片后无需返回全局导航，直接点击“去作答”，聚焦答案输入；回答后同位置可跳转反馈，答案区支持返回图像。
- 点击放大或在页面中跳转时不丢失当前答题输入、作答历史或试题编号，既有本机存储键不得变更。
- 所有新增按钮必须有可见焦点、足够触摸尺寸，遵守 `prefers-reduced-motion`。

## 自动化验证

- `qa/browser-lumen.mjs`：主站首页平面样式、侧栏字标可辨性、Skin comparison 的正文表格宽度/证据图、跨模块导航以及全站浏览器交互。
- `qa/browser-image-quiz.mjs`：手机双向跳转和正确聚焦、桌面无重复跳转按钮、放大图、恢复题目、导入备份等。
- `image-quiz/qa/validate_project.mjs`、`runtime_smoke.mjs` 及原有 `qa/validate-*.mjs`：题库完整性、进度逻辑、术语学习回归。
- 截图是审美证据，CI 绿灯只证明测试覆盖的行为满足断言，不代表所有页面已获奖级审美或医学专家审定。
